How this works

  1. Your browser makes a secret key that never leaves your computer.
  2. You paste your applicant names. Your browser turns each name into a point on an elliptic curve and scrambles it with your key. Only these scrambled values are uploaded.
  3. Each program then applies its own key to every other program’s scrambled list. The scrambling commutes, so once every program has touched every list, the same name ends up as the same value no matter who submitted it — but no one, including the server, can turn a value back into a name.
  4. The organizers learn only how many scrambled values are shared between programs.

This is the standard Diffie–Hellman private set intersection protocol, using the ristretto255 group. All cryptography runs in your browser; you can read the code via “view source”.
